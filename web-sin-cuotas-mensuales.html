una web sin cuotas mensuales

muchas webs se alquilan: una cuota por el constructor, otra por el alojamiento, otra por el mantenimiento. el día que dejas de pagar, la web desaparece. y no es tuya.

las nuestras funcionan al revés: pagas una vez el diseño y la programación, y la web es tuya. el código, el dominio y la cuenta donde está publicada.

por qué no hay cuota

porque no hay nada que cobrar cada mes. la web son archivos estáticos, sin servidor ni base de datos, publicados desde una cuenta de cloudflare o github a tu nombre cuyo plan gratuito cubre de sobra un proyecto así. nada que mantener, nada que pueda caerse.

  • estructuras3000 una web para colectivizar materiales
  • miranda una web para diseño editorial

lo único que se renueva: el dominio

lo compras tú y queda a tu nombre; te ayudamos a elegirlo y a configurarlo. si algún día caduca, la web deja de verse, pero los archivos siguen siendo tuyos y se pueden volver a publicar.

  • berta esteve una web para curaduría, expos y jajas
  • andrea carilla una web para fotografía de moda y editorial

el código es tuyo y tú la actualizas

al entregar te pasamos una copia entera a tu cuenta de github, y sales de la última reunión sabiendo cambiar textos, imágenes y archivos. no necesitas pagarnos para cambiar una fecha o subir una foto. así es la entrega →

  • vicios torpes una web para un estudio de tatuaje
  • paula barjau una web para maquillaje y peluquería

y si algo falla

dos semanas de garantía; después, los cambios se cobran por horas y solo cuando los pides. sin mantenimiento obligatorio. si el proyecto necesita algo que no sea estático —una tienda, reservas— se presupuesta aparte y va igualmente en tus cuentas. la letra pequeña →

para quién tiene sentido

para quien quiere una web que dure: artistas, estudios, asociaciones y pequeños negocios como un estudio de tatuaje o una maquilladora, que no quieren otra suscripción más.
