una web sense quotes mensuals

moltes webs es lloguen: una quota pel constructor, una altra per l'allotjament, una altra pel manteniment. el dia que deixes de pagar, la web desapareix. i no és teva.

les nostres funcionen al revés: pagues un cop el disseny i la programació, i la web és teva. el codi, el domini i el compte des d'on està publicada.

per què no hi ha quota

perquè no hi ha res a cobrar cada mes. la web són arxius estàtics, sense servidor ni base de dades, publicats des d'un compte de cloudflare o github a nom teu, amb un pla gratuït que cobreix de sobres un projecte així. res a mantenir, res que pugui caure.

  • estructuras3000 una web per a col·lectivitzar materials
  • miranda una web per a disseny editorial

l'únic que es renova: el domini

el compres tu i queda a nom teu; t'ajudem a triar-lo i a configurar-lo. si algun dia caduca, la web deixa de veure's, però els arxius continuen sent teus i es poden tornar a publicar.

  • berta esteve una web per a curadoria, expos i jajas
  • andrea carilla una web per a fotografia de moda i editorial

el codi és teu i tu l'actualitzes

en entregar et passem una còpia sencera al teu compte de github, i surts de l'última reunió sabent canviar textos, imatges i arxius. no necessites pagar-nos per canviar una data o pujar una foto. així és l'entrega →

  • vicios torpes una web per a un estudi de tatuatge
  • paula barjau una web per a maquillatge i perruqueria

i si alguna cosa falla

dues setmanes de garantia; després, els canvis es cobren per hores i només quan els demanes. sense manteniment obligatori. si el projecte necessita alguna cosa que no sigui estàtica —una botiga, reserves— es pressuposta a part i va igualment als teus comptes. la lletra petita →
