projecte · una web per a cinema analògic i performance

barbara wong

la bárbara treballa amb cinema analògic, videoinstal·lació, performance i escriptura des d'una perspectiva ecofeminista. la seva web reuneix obra, notícies i un diari — tres ritmes de publicació diferents en una sola casa. la vam muntar perquè ella la pugui alimentar sense tocar codi: edita uns fitxers de text i la web es reorganitza sola. són molts anys de feina, i amb aquest volum la temptació és estrènyer-ho tot. vam fer el contrari: una web molt neta, amb aire, perquè cada peça es vegi sola.
