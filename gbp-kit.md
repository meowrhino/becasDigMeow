# kit para el alta en Google Business Profile

> Alta en **[business.google.com](https://business.google.com)** con tu cuenta de Google.
> Son ~15 minutos + una verificación que Google puede pedir por vídeo o correo postal.
> Todo lo de abajo es copiar-pegar o elegir opción.

## Datos básicos

| Campo | Qué poner |
|---|---|
| Nombre del negocio | `meowrhino studio` |
| Categoría principal | **Diseñador de sitios web** (Website designer) |
| Categorías secundarias | Empresa de diseño de sitios web · Consultor informático |
| ¿Tienda física? | **No** → elegir "empresa de servicios en el área" (Service Area Business). Así no publicas tu dirección personal, pero Google te sitúa en el mapa de Barcelona. |
| Área de servicio | Barcelona (puedes añadir: L'Hospitalet, Badalona, área metropolitana) |
| Teléfono | el que quieras hacer público — **importante**: el mismo que pongamos luego en el JSON-LD de la web |
| Web | `https://meowrhino.studio` |
| Horario | el que hagas de verdad (p. ej. lu–vi 10:00–18:00). Mejor honesto que 24/7. |

## Servicios (añádelos como "servicios" en la ficha)

- diseño web a medida — desde 850 € *(ojo: si el cupón caduca a final de agosto, revisa el precio antes)*
- web para artistas y portfolios
- web para pequeños negocios
- mantenimiento web (opcional)
- configuración de dominio y correo
- formación: aprende a mantener tu web

## Fotos (sube mínimo 3–5)

- El logo / favicon en grande.
- Capturas de 4–6 webs de clientes (ya las tienes en `img/` del repo, las 1.webp).
- Si tienes cara visible como marca, una foto tuya trabajando ayuda — los perfiles con caras convierten más.

## Después del alta (lo que de verdad hace rankear la ficha)

1. **Reseñas**: crearts tiene 4.9★ con 34 reseñas; tú 0. Pide reseña a los ~20 clientes
   (son artistas contentos con su web — es la lista de peticiones más fácil del mundo).
   Desde la ficha: botón "Pedir reseñas" te da un enlace corto para mandar por WhatsApp.
   Pide 2–3 por semana, no 20 de golpe (a Google le huelen mal los picos).
2. **Publica de vez en cuando**: cada web entregada es un "post" de la ficha (foto + 2 líneas + enlace).
3. Cuando la ficha esté verificada, **avísame**: actualizo el JSON-LD de la web para que
   apunte a la ficha (`sameAs` + teléfono) y todo quede atado.
